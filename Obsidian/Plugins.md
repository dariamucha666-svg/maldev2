# Wtyczki

Zainstalowane w `.obsidian/plugins/` (sklep / GitHub). Włączone w `community-plugins.json`.

| Wtyczka | ID | Po co |
|---------|-----|--------|
| Dataview | `dataview` | Tabele projektów / malware / IOC |
| Tasks | `obsidian-tasks-plugin` | `Backlog` i checkboxy z datami |
| Calendar | `calendar` | Widok `Daily/` |
| Excalidraw | `obsidian-excalidraw-plugin` | Schematy |
| Git | `obsidian-git` | Wersje lokalne (bez auto-push) |
| Templater | `templater-obsidian` | Szablony w `_Templates/` |
| QuickAdd | `quickadd` | Nowa analiza / IOC / projekt |
| Kanban | `obsidian-kanban` | [[Kanban]] |
| Auto Note Mover | `auto-note-mover` | tag → folder |
| Waypoint | `waypoint` | Spis folderu (`%% Waypoint %%`) |
| Homepage | `homepage` | Start na [[Dashboard]] |

Po pierwszym otwarciu vaultu w Obsidian: Settings → Community plugins → Restricted mode **off**. Wtyczki są już na dysku — nie trzeba ich ściągać ponownie.

Szablony: folder `_Templates`. Daily notes: folder `Daily`, szablon `_Templates/Dziennik_Lab`.
