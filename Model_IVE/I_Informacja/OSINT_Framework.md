# OSINT Framework

**TL;DR**: strona internetowa (osintframework.com) — **interaktywny index** narzędzi
OSINT pogrupowanych wg kategorii (email, username, domain, IP, social…).

## Co to / do czego

To nie narzędzie, a **mapa/kolokacja** setek narzędzi OSINT w formie drzewa.
Klikasz kategorię → dostajesz listę narzędzi + linki.

## Kategorie

- Username / Email / Phone / Domain / IP Address
- Social Networks / People Search
- Dark Web / Cryptocurrency
- Malicious file / Threat intelligence

## Jak używać

1. Wejdź na https://osintframework.com
2. Wybierz kategorię (np. `Domain Name` → `DNS` → lista narzędzi).
3. Wybierz pasujące narzędzie (wiele z nich mamy tutaj: theHarvester, Recon-ng, Shodan…).

## Rola w modelu I-V-E

Służy jako **ściąga**: gdy fazie I brakuje jakiegoś źródła, sprawdzasz OSINT Framework
i dodajesz narzędzie do arsenału.
