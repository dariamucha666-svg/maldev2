## 4. Analiza próbki (static only)

Próbka: `141935c46a5c4ff1b84b433e84f36e61.exe`  
SHA256: `178cb931cc846c4ac7bbf2370259e8b9f7d8a45459974115818b5c1e608533c4`

### Pipeline / pefile / strings / YARA

- PE32+ GUI x64, Go **1.25.4**, `-trimpath`, timestamp 1970.
- Moduł Ghidra: `cbmUfIHKAjbygau` (losowa nazwa, wygląd **garble**).
- Motyw stringów: *Precision Agriculture* + *elevator/cabin*.
- **0 URL, 0 IP** w plaintext.
- YARA `IsPacked` — raczej FP (Go `.rdata` ~7.16).
- Overlay 2408 B; YARA `HasDigitalSignature` vs brak katalogu Security w pefile.
- IAT: tylko `kernel32.dll` (46 funkcji). Reszta przez `LoadLibrary` / `GetProcAddress`.

### Ghidra na `.57` (headless)

- Próbka skopiowana jako `C:\Tools\samples\backdoor.exe` — **hash zgodny, nie uruchamiana**.
- Auto Analysis ~44 s, **~1930 funkcji**.
- To **nie** pełny implant Sliver (za mały, brak typowego stosu C2 w pakietach).
- Funkcje `main.*` zaciemnione, m.in.:

| Symbol | Adres | Rola (robocza) |
|--------|-------|----------------|
| `main.main` | `0x1400eb220` | entry logiki |
| `main.itnlwdcdwymtd` | `0x1400b9460` | resolver API (`GetProcAddress`) |
| `main.init` + ~20 innych `main.*` | — | zaciemnione helpery |

- W stringach / late-bind widać m.in. `NetUserAdd/Del`, `NetShareAdd/Del`, `LogonUserW`, `ImpersonateLoggedOnUser`, `RegSetValueExW`, `RegDeleteKeyW`, `CreateProcessW`, `OpenSCManagerW`.
- Hipoteza otwarta: żywe API vs martwe symbole `x/sys`. Dekompilacja `main.main` + resolvera była w toku (skrypt `DecompTwo.java`).

## 7. Czego jeszcze nie domknęliśmy

1. Pełna dekompilacja `main.main` + `main.itnlwdcdwymtd` (skrypt Ghidry mógł jeszcze nie dokończyć).
2. Overlay 2408 B — hexdump / czy to cert.
3. capa z dłuższym timeoutem.
4. Lista `main.*` z `.symtab` (`go tool nm` / `rabin2 -s`).
5. PEStudio / x64dbg offline (bez sieci) — tylko jeśli trzeba potwierdzić żywe API.
6. Instalacja binarki Obsidian (niekonieczna — vault działa jako folder).
