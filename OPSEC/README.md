# OPSEC — jak nie wyłożyć siebie w sieci

Baza wiedzy o **Operational Security (OPSEC)** i **cyberhigienie**: jak chronić tożsamość,
konta, urządzenia i komunikację. Zaczynasz od [[Zabezpieczenia_po_prostu]] — to wersja „w pigułce".
Głębiej: [[Podstawy_OPSEC]] (czym jest OPSEC, model zagrożeń, 5 kroków).

> **Zasada:** OPSEC to nie paranoja ani „zniknięcie". To świadome decydowanie, co i komu pokazujesz.
> Najpierw [[Zabezpieczenia_po_prostu]], potem konkretne tematy, na końcu [[Checklist_OPSEC]] cyklicznie.
