# Checklist OPSEC

Lista do odhaczania. Cotygodniowo (5 minut) + wersja kryzysowa.

## Raz na tydzień (5 min)

- [ ] Aktualizacje systemu / telefonu / routera zainstalowane
- [ ] Backup wykonany i zweryfikowany
- [ ] Alerty o wyciekach (HaveIBeenPwned) — sprawdzone
- [ ] Aktywne sesje kont (mail, bank, social) — przeglądnięte, nieznane wylogowane
- [ ] Podpięte aplikacje do kont (Google/Meta/GitHub) — przeglądnięte
- [ ] 2FA działa na kluczowych kontach (mail, finanse, krypto)

## Raz na kwartał (głębszy przegląd)

- [ ] OSINT na sobie (wyszukiwarka: imię, nick, numer, stary mail)
- [ ] Lista kont: usunięte martwe, zaktualizowane hasła tam gdzie słabe
- [ ] Kody zapasowe 2FA nadal dostępne i aktualne
- [ ] Przegląd „co o mnie wisi" w social media (stare posty, tagi, zdjęcia z meta)
- [ ] Router: zmienione hasło, aktualny firmware, lista podłączonych urządzeń
- [ ] Hasło główne menedżera — nadal mocne i niepowtarzalne

## Kryzysowa (podejrzenie włamania / kliknięty zły link)

- [ ] Odłącz internet (tryb samolotowy / kabel)
- [ ] Nie loguj się do banku / maila / krypto z tej maszyny
- [ ] Skan (Defender offline / Malwarebytes) + odinstaluj podejrzane
- [ ] Zmień hasła z czystego urządzenia: mail → bank → krypto → reszta
- [ ] Wyloguj wszystkie sesje wszędzie
- [ ] Sprawdź reguły maila (przekierowania, filtry) i podpięte aplikacje
- [ ] Zgłoś tam, gdzie trzeba (bank, operator, CERT, policja przy kradzieży tożsamości)
