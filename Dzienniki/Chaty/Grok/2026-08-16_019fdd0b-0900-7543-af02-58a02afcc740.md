### 🤖 Asystent

Ten skrypt to typowy workflow z **MalwareBazaar** (pobranie sample → rozpakowanie → wrzucenie APK do Drive). Wygląda na analizę, nie na atak — poniżej co robi i co w nim nie gra.

## Co robi

1. Buduje URL do sample po hashu  
2. Pobiera ZIP (`wget`)  
3. Rozpakowuje hasłem `infected` (standard abuse.ch)  
4. Kopiuje `*.apk` na Google Drive przez `rclone`  
5. Czyści pliki lokalne  

## Problemy w skrypcie

| Problem | Szczegóły |
|--------|-----------|
| **HASH ucięty** | `a0fda1e0331abd159c86e...` — trzeba pełnego SHA256 |
| **URL** | `https://bazaar.abuse.ch/sample/$HASH/` to strona HTML, nie bezpośredni plik. Do pobrania zwykle API: `https://mb-api.abuse.ch/api/v1/` (`query=get_file`, `sha256_hash=...`) albo link z API po logowaniu |
| **Brak cudzysłowów** | `wget -O temp.zip $URL` → bezpieczniej `"$URL"` |
| **`*.apk`** | Może nie złapać pliku, jeśli nazwa jest inna / w podkatalogu |
| **Brak obsługi błędów** | Przy failu `wget`/`unzip` i tak poleci `rclone` / `rm` |
| **Bezpieczeństwo** | Rozpakowanie malware na hoście bez izolacji (VM/sandbox) jest ryzykowne |

## Poprawiona wersja (szkic)

```bash
#!/bin/bash
set -euo pipefail

HASH="PEŁNY_SHA256_TUTAJ"
OUTDIR="$(mktemp -d)"
ZIP="$OUTDIR/sample.zip"
API_KEY=<REDACTED>  # opcjonalnie, jeśli wymagane

cleanup() { rm -rf "$OUTDIR"; }
trap cleanup EXIT

# Pobranie przez API MalwareBazaar
curl -sS -X POST 'https://mb-api.abuse.ch/api/v1/' \
  -d "query=get_file" \
  -d "sha256_hash=${HASH}" \
  -o "$ZIP"

# Sprawdź, czy to ZIP, nie JSON z błędem
file "$ZIP"
unzip -P infected -d "$OUTDIR" "$ZIP"

# Tylko APK → Drive
find "$OUTDIR" -type f -name '*.apk' -print0 \
  | xargs -0 -r rclone copy -v --files-from-raw - gdrive:MojaAnaliza/
# albo prościej, jeśli pliki leżą bezpośrednio:
# rclone copy "$OUTDIR" gdrive:MojaAnaliza/ --include "*.apk"
```

- Pełny hash SHA256 jest obowiązkowy  
- `rclone` musi mieć skonfigurowany remote `gdrive`  
- Lepiej robić to w **VM / izolowanym środowisku**, nie na głównym systemie
