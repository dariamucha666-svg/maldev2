Format: **krótki podpis + film z roboty**. Tekst max ~500 znaków. Mówisz jak do kolegi, nie jak z podręcznika.

## Zasady

1. Prosty język. Krótkie zdania. Zero żargonu, albo jedno słowo i od razu co znaczy.
2. To portfolio: widać ręce, ekran, efekt. Nie wykład.
3. Pieniądze = skill (strona, apka, treść, praca). **Nie** „zarób na wirusie”.
4. OPSEC = jak nie wyłożyć siebie (adres, szkoła, tokeny, foty biurka z listami). Nie „jak ukryć atak”.
5. Malware: tylko co to robi i jak nie wejść. Nigdy jak napisać / odpalić / sprzedać.
6. Hasła i tokeny poza postem.
