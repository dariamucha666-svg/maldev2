# Recap — 16.08 (rozbudowa pipeline: PE/ELF + narzedzia wspolne)

Sesja: przeglad workspace (pentester/red team) → wybor punktu 1 z listy (rozbudowa pipeline)
→ 4 narzedzia + hook do pipeline.sh + dokumentacja.
Powiązane: [[Pipeline_PE_ELF]] · [[Analyze_APK_Pipeline]] · [[Dashboard_IOC]] · [[Automatyzacja]] · [[IVE_MOC]]

## Co zrobiono (chronologicznie)

1. **Przeglad workspace** — pipeline APK (`analyze_apk.py`), model I-V-E, lab RedTeam_AD,
   integracja Sliver, YARA/Sigma/Suricata, boty Telegram.
2. **analyze_pe.py** — pipeline PE/ELF (statyczna):
   - PE (pefile): naglowki, timestamp, sekcje+entropia, importy/eksporty, overlay,
     TLS callbacks, podejrzane API → kategorie (injection/persistence/evasion/keylog/...),
     heurystyki packera (UPX, wysoka entropia, malo importow).
   - ELF (parser wbudowany, bez zaleznosci): sekcje+entropia, symbole UND (importy),
     DT_NEEDED, BuildID, UPX/Go.
   - strings → IoC (IP/URL/domeny) → klasyfikator roli (regulowy, confidence + powody)
     → skan YARA → generacja reguly YARA (markery + magic) → karta Obsidian → raport JSON
     → upsert do `iocs.json`.
3. **ioc_to_stix.py** — agregator: raporty + `iocs.json` → dedupe po SHA256 i (typ, wartosc)
   → STIX 2.1 (bundle: identity + TLP + indicators + observed-data), CSV (SOC), JSON (dashboard).
4. **yara_gen_test.py** — generator regul (markery z probki/raportu, priorytet dla IoC)
   + tester TP/FP/FN, precision/recall/F1 (korpus `corpus/<family>/` lub `--labels`)
   + tryb `scan` (wylistowanie dopasowanych stringow).
5. **dash-cli.py** — CLI dashboardu: `stats` / `timeline` / `filter` (z `--json`)
   / `chart` (wykresy ASCII) / `iocs` / `report <hash|nazwa>` (MD/HTML, PDF przez wkhtmltopdf/weasyprint/chromium).
6. **export_iocs_hook.sh** — hook do `pipeline.sh` (niekrytyczny, exit 0);
   env: REPORTS_DIR / IOC_EXPORT_DIR / IOC_TLP / IOC_OBSERVED / IOC_PUBLIC_DIR.
7. **Dokumentacja** — `Pipeline_PE_ELF.md` + wiersze w `Automatyzacja.md` (tabela + sekcja hooka).
