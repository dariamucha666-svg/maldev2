# Logs

Automatyczne logi z VPS `.133`. Nie edytuj ręcznie — dopisują je `script`, pipeline i cron.

- `terminal_YYYY-MM-DD.log` — sesje interaktywnego bash
- `pipeline_YYYY-MM-DD.log` — ostatni run pipeline
- `sliver_YYYY-MM-DD.log` — wycinek `journalctl -u sliver`
